字幕总结 设置

把 B站视频字幕变成可读、可导出的 AI 笔记

打开 Bilibili
01

AI 服务

支持 DeepSeek、OpenAI 以及任意 OpenAI Chat Completions 兼容接口。

测试会发送一条极小的请求，可能产生少量费用。
02

总结偏好

控制 AI 如何组织内容。长视频会自动分段提炼，再合并成完整总结。

03

导出选项

字幕和总结都可以在页面面板中导出，不需要额外的下载权限。

使用步骤

  1. 打开视频进入任意 B站视频或番剧播放页。
  2. 点击悬浮按钮页面右侧「字幕总结」，或点击扩展图标打开面板。
  3. 加载字幕选择语言，面板会自动获取字幕列表并下载。
  4. 生成与导出生成 AI 总结，按需导出 SRT / TXT / Markdown。

隐私说明

  • 各服务商的 API Key 按域名分别保存在 chrome.storage.local，不会上传到本扩展的服务器。
  • 字幕仅发送给你配置的 AI 接口用于生成总结。
  • 扩展没有统计、埋点或远程代码。
  • 自定义 API 域名会通过浏览器权限弹窗单独授权。

没有字幕？

B站只为部分视频提供字幕。若提示需要登录，请先在 B站登录；若仍为空，通常说明该视频尚未生成字幕或字幕被锁定。

获取失败时，可以刷新 B站页面后重试；B站接口偶尔会触发风控。
